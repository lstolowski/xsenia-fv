# ZAD-014. Dane testowe: faktury zakupowe na KSeF TEST

- User story: US-004
- Status: Do zrobienia
- Szacunek: S

## Cel

Na NIP testowym muszą istnieć faktury zakupowe, aby przetestować listę zakupową.

## Zakres

- [ ] Ustalić sposób: wystawienie faktur z innego testowego NIP (drugi token / kontekst) na nasz NIP testowy
- [ ] Narzędzie/test integracyjny generujący kilka faktur zakupowych o różnych datach dostawy (także z `P_6` różną od `P_1` i faktury korygującej)

## Uwagi

- Do ustalenia: skąd drugi kontekst na TEST (token dla innego NIP)

- [ ] Testy
- [ ] Sprawdzone na środowisku KSeF TEST / emulatorze (jeśli dotyczy)
